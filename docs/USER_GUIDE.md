# 用户使用手册

## 1. 登录

浏览器打开 `http://<服务器>:8080`，使用管理员账号登录（默认 `admin / admin123`）。

## 2. 创建项目

右上角「+ 项目」输入名称创建。项目是数据隔离单位，所有资产、任务、漏洞均归属项目。

## 3. 导入资产

进入「资产导入」页面，粘贴授权目标，支持：

```
192.168.1.1              # 单 IP
192.168.1.0/24           # CIDR（超过 /12 的范围会被拒绝）
192.168.1.10-192.168.1.20 # IP 段
example.com              # 域名
https://app.example.com  # URL
```

系统自动去重并区分公网/内网。

## 4. 创建扫描任务

进入「扫描任务」→「+ 创建扫描任务」：

- **快速模式**：空间测绘 + 常见端口扫描（最快）
- **标准模式**：空间测绘 + Top1000 端口扫描 + 全部漏洞扫描（内置风险检测 + 规则库）
- **深度模式**：空间测绘 + 全端口扫描（1-65535）+ 全部漏洞扫描 + URL/API 发现（最慢）

三种模式均执行空间测绘与端口扫描；任务中显式指定端口时覆盖模式默认端口集。

可配置端口（空=常用端口 / `80,443` / `1-1000` / `full` 全端口）、并发数、超时、优先级，以及
**扫描周期**（一次性 / 每 8 小时 / 每 24 小时 / 每周）——设置周期后任务成为资产监控任务，
到期自动重新执行，每次新增的资产/端口/Web/漏洞自动进入「变化监控」。

任务运行中可**暂停 / 恢复 / 终止**，可查看实时日志。

## 5. 查看资产

「资产管理」包含五个视图：

- 支持**导出 CSV / JSON**（按当前视图类型导出对应资产）。
- **IP**：存活状态、探测方式、风险评分。点击任意 IP 打开**资产画像**，查看其关联的域名、开放端口/服务（含自动分类）、Web 资产与技术栈、关联漏洞。
- **域名 / 端口 / Web / URL**：对应资产列表，支持搜索。

## 6. 漏洞风险

「漏洞风险」页按等级（Critical/High/Medium/Low/Info）过滤查看，包含漏洞名称、影响资产、端口、URL、组件、修复建议；可一键导出 CSV / JSON。

## 5.1 资产白名单

「系统设置 → 资产白名单」配置不做漏洞扫描的资产（每行一项）：精确 IP、CIDR 网段、域名
（自动覆盖子域名，支持 `*.corp.cn` 写法）。白名单内的资产在扫描任务与 POC 监控触发的全资产
扫描中都会**跳过漏洞扫描动作**（内置风险检测与规则引擎），但资产发现、端口扫描、Web 识别照常执行。

任务列表与资产管理页均支持**删除**：任务删除（运行中先终止，连带日志）、五类资产的删除。

## 6.1 漏洞规则库（PoC 检测）

「漏洞规则库」页支持导入 nuclei / xray / afrog 三种 YAML PoC，导入方式：

1. **POC 文件仓库**：把 POC 放入 `data/poc` 对应类型目录（页面可上传，自动归类），进入目录点「导入当前目录到规则库」
2. **模板源更新**：配置 GitHub 模板仓库源后「立即更新」，自动 clone/pull 并导入
3. **API**：`POST /api/vuln-rules/import {"path":"服务器目录"}` 仍可用于批量导入
2. 用来源/等级/启用/可执行筛选与搜索管理规则；每条可「测试」（对指定 URL 单规则试探）、
   查看 YAML 原文、停用、删除
3. 深度扫描任务默认对每个 Web 资产执行**全部**启用的可执行规则（「规则执行设置」中默认开启，
   每目标最大规则数 0 = 加载全部；如需控制耗时可改为具体条数），
   命中的 PoC 直接进入漏洞列表（组件列标注规则来源）

说明：部分规则使用引擎暂不支持的表达式（复杂 CEL/DSL 函数、search 回填、raw 请求等），
此类规则入库但标记「不可执行」，不会在扫描中运行。规则发起的均为 HTTP 请求，请确保仅对授权资产启用。

**POC 文件仓库**：`data/poc` 目录是平台统一存放 PoC 文件的仓库，页面上可分级浏览（面包屑导航）、
新建文件夹（支持一次创建多级，如 `web/rce`）、上传 .yml/.yaml 文件（上传前自动校验规则格式）、
**上传文件夹**（一次选择整个本地目录，即上传其中的所有 POC 文件：忽略所选文件夹本身的名字、
保留其内部子目录结构，自动过滤非 yaml 文件，文件按格式自动归入 xray/nuclei/afrog 类型目录，
如所选 `my-pocs/web/a.yaml` 落位 `nuclei/web/a.yaml`）、删除文件/目录、以及把当前目录一键导入规则库。
也可直接把 PoC 文件手工拷贝到 `data/poc` 子目录后在页面导入。

**POC 目录监控**：启用后（默认开启，默认每 60 秒检查一次，可在界面调整）自动监视 `data/poc` 目录——
发现新增或变更的规则文件即自动导入规则库，并立即用这些新规则对**所有项目的全部 Web 资产**执行一轮
漏洞扫描，检出的漏洞直接入库（来源标注 POC 监控）并写入变化监控。把新 PoC 文件丢进 `data/poc` 对应类型
目录即可自动生效，无需任何手动操作。

**模板源在线更新**：支持配置 GitHub 模板仓库源（默认为空，自行添加），「立即更新」会
clone --depth 1（已存在则 fetch + 重置到远端最新）并自动导入规则库；「每日自动更新」开关与**更新时间**（默认 02:00，可改）即时保存，每日到点自动拉取；更新时会与库中已有规则对比，
**仅对本次新增的 POC 自动触发全部资产的漏洞扫描**（更新的旧规则不重复触发）；克隆默认存放在 **POC 仓库的 nuclei 类型目录**
（`data/poc/nuclei/owner/repo`，可在文件仓库页面浏览），更新期间自动暂停 POC 目录监控避免误触发全资产扫描；GitHub 直连失败时自动加镜像前缀重试
（默认 `https://ghproxy.com/`，可在界面改为其他可用镜像）；可开启每日自动更新。源列表顺序即优先级，
不同仓库的重复模板保留先到（官方库建议放最前）。

## 6.2 资产监控

「资产监控」页集中管理所有配置了扫描周期的任务：显示周期、当前状态、上次结束时间与下次执行时间，
支持「立即执行」「暂停 / 恢复 / 终止」。调度器每分钟检查一次，任务结束时间 + 周期到期后自动重新排队。

**新增资产默认漏洞扫描**：周期任务每轮执行结束后，与上一轮对比（基于本轮变化记录），凡本轮**新增的
Web 资产**会自动执行一次漏洞扫描（内置风险检测 + 规则库，即使任务是快速模式；白名单资产仍跳过），
任务日志记录「本轮新增 N 个 Web 资产，默认执行漏洞扫描」。

## 7. 变化监控

「变化监控」记录每次扫描新增的 IP、端口、Web、URL、漏洞——再次扫描同一目标后，新增项会自动出现在这里。

## 8. 报告导出

- 漏洞页支持 CSV / JSON 导出；
- API `GET /api/export?type=...&format=csv|json` 支持全部资产类型导出；
- `GET /api/reports` 返回含统计、高风险资产 Top、漏洞详情的汇总 JSON，可直接用于报告生成。

## 9. 角色权限

- **admin**：全部功能
- **auditor**：查看 + 任务控制 + 资产导入
- **viewer**：仅查看

## 10. 安全与合规

- 仅对已授权目标发起扫描；
- 全部检测为非破坏性（GET 请求 / Banner / TLS 握手）；
- 所有登录与关键操作均记录审计日志（`GET /api/system/logs`）。
